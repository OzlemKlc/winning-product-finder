# Five-minute community demo

This demo shows how Codex can help builders create an explainable research-to-creative workflow while keeping deterministic decisions visible.

## Audience

Developers, ecommerce founders, growth teams, and first-time AI builders.

## Preparation

1. Start the application in demo mode with `npm start`.
2. Open <http://localhost:4545>.
3. Keep AdForge running separately for the handoff step.

## Live flow

1. Search for `led` without any API key.
2. Explain the 100-point score and why each component is deterministic.
3. Show Hook Radar and compare pattern strength with simple frequency.
4. Open a generated 15-second UGC brief.
5. Copy the JSON output into AdForge competitor research and generate new, non-copying hook variants.

## Learning outcome

Participants learn when rules are more trustworthy than a model, when structured model interpretation adds value, and how to pass evidence between two small tools through a transparent JSON contract.

## Workshop extension

In a 60-minute workshop, teams can add one provider, one hook pattern, or one scoring signal; write a test; and compare the effect on the same demo dataset. The session can run without paid accounts.
