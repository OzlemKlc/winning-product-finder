# Contributing

Keep contributions to Winning Product Finder small, verifiable, and focused on one purpose.

## Commit policy

- The person submitting a change remains its commit author.
- Automation tools and coding assistants are not added as commit authors or co-authors.
- When a tool affects runtime behavior, document that technical dependency in the code or project documentation.
- Commit messages should describe the change and, when relevant, how it was verified.

## Before submitting

1. Run `npm test`.
2. Document new environment variables in `.env.example`.
3. Never commit API keys, personal data, or local output files.
4. Update the README or architecture notes when behavior changes.
